## 🇪🇸 Español: Política de Privacidad

### 1. Compromiso de Privacidad
`dbv-eer-studio` es una herramienta educativa y de ingeniería de software distribuida bajo licencia MIT de código abierto. **Respetamos profundamente la privacidad de nuestros usuarios**: la aplicación opera de forma 100% local, privada y offline.

### 2. Recopilación y Uso de Datos
- **Sin Datos Personales:** La aplicación NO recopila, almacena, procesa ni transmite ningún tipo de información personal identificable.
- **Sin Telemetría ni Analítica:** NO se utilizan herramientas de seguimiento, rastreo, cookies, analíticas de terceros ni servicios de telemetría.
- **Sin Almacenamiento en Servidores:** Todos los diagramas EER, modelos relacionales y scripts SQL creados o editados en la aplicación permanecen exclusivamente en el dispositivo local del usuario.

### 3. Conexiones de Red
- **Versión de la Microsoft Store (MSIX):** La aplicación no realiza ninguna llamada ni conexión a servidores externos.
- **Versión Web / GitHub Release:** Únicamente en las versiones instaladas fuera de tiendas oficiales se incluye una función opcional de comprobación de actualizaciones que consulta la API pública de GitHub Releases para verificar si existe una nueva versión compilada.

### 4. Permisos del Dispositivo
La aplicación requiere exclusivamente permisos locales para acceder al sistema de archivos mediante diálogos estándar del sistema operativo (File System Access API) cuando el usuario decide explícitamente abrir o guardar archivos `.eer`, `.sql` o `.svg`.

## 🇬🇧 English: Privacy Policy

### 1. Privacy Commitment
`dbv-eer-studio` is an open-source educational software suite released under the MIT License. **We strongly value your privacy**: the application operates 100% locally, privately, and offline.

### 2. Data Collection and Usage
- **No Personal Data Collection:** The application DOES NOT collect, store, process, or transmit any personally identifiable information.
- **No Telemetry or Analytics:** NO third-party tracking, analytics, cookies, or telemetry tools are integrated into the application.
- **No Remote Server Storage:** All EER diagrams, relational models, and SQL scripts created or edited remain strictly on the user's local device.

### 3. Network Connections
- **Microsoft Store Version (MSIX):** The app makes zero network requests to external servers.
- **Web / GitHub Release Version:** An optional update-checker feature in direct installer versions queries the public GitHub Releases API to notify users of new available releases.

### 4. Device Permissions
The app only requests standard local OS file dialog permissions (File System Access API) when the user explicitly chooses to open or save `.eer`, `.sql`, or `.svg` files.
